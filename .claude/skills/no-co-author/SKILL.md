# No co-authors

**TO NEVER COAUTHOR WORK AGAIN!**

Git commits have one author: the human who asked for the commit. Never attribute Cursor, Claude, Grok, the agent, or any tool.

## Forbidden

- `Co-authored-by` trailers (any name, including `Cursor <cursoragent@cursor.com>`)
- `Signed-off-by` for the agent or any tool
- `--author`, `--trailer`, or any flag that changes authorship
- "Generated by", "Assisted by", or similar in the commit message
- Proceeding with a commit whose message contains those lines

The commit message is the human's. The author is the human's git identity.

## After every `git commit`

Cursor may append `Co-authored-by` after the message you wrote. That is still a violation.

1. Run `git log -1 --format=%B`
2. If the message contains `Co-authored-by` or `Signed-off-by: Cursor`, **do not push**
3. Rewrite HEAD with `git commit-tree` (same tree, same parent, same author, cleaned message) then `git reset --hard` to that commit
4. Confirm `git log -1 --format=%B` has no trailer
5. Only then push

Do not use `git commit --amend` if that path re-injects the trailer. Use `commit-tree`.

A helper is `scripts/strip-head.sh` in this skill directory.

## Hooks

`scripts/commit-msg` strips agent trailers at commit time. Copy it to `.git/hooks/commit-msg` in the repo you are committing to (mode `0755`). Committed copy: `.githooks/commit-msg`.
